## 💻 Understanding the For Loop

A `for` loop consists of three main parts:

```javascript
for (initialization; condition; update) {
    // Code to execute
}
```

**How it works:**

1. **Initialization:** Runs once before the loop starts.
2. **Condition:** Checks whether the loop should continue.
3. **Update:** Changes the loop variable after each iteration.
4. **Execution:** Runs the code inside the loop whenever the condition is true.

### Example

```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
```

**Output:**

```text
1
2
3
4
5
```
